# Welcome to your SoundWave project

## Project info

This webpage looks and feels just like a music player, where all the pieces work together. When you click a playlist on the side, the main area instantly shows *only* the songs from that specific playlist. Then, when you click the "play" button on any song, the player bar at the very bottom immediately updates to show the song you just picked. It's all one connected experience, where clicking one thing makes the other parts of the page change to match.

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
